Setup & privacy

Live voice uses YAP for local transcription (final segments, explicit Send turn). Complete its native setup and set YAP_READY=1. It also needs three values in your private local .env: OPENAI_API_KEY, ELEVENLABS_API_KEY, and an existing authorized ELEVENLABS_VOICE_ID. Restart the server after setup. Never enter secrets on this page or in chat.

Checking setup…

Microphone capture pauses during replies to prevent feedback. Use “Interrupt & talk” to cut audio and begin a new turn. Stop, Escape, switching tabs, or closing this page releases the microphone and cancels the session. The app does not save recordings or transcripts; providers apply their own data policies. API usage is billed separately from a ChatGPT or Codex subscription. See README for setup and model controls.
